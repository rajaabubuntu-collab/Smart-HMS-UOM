# Synthetic email previews

These files contain fictional patients, appointments and payments. No email was sent. The reset token is a nonfunctional placeholder. Open an HTML file to inspect the layout; TXT files contain the subject and plain-text alternative. Portal links point to the local development app.

Generated by `node scripts/verification/email-previews.mjs`. Layout checked in Chromium at 960, 390 and 320 pixels; this is not a claim of rendering validation in every email client.
